# 수월재 (水月齋)

달빛 아래 피어나는 운명의 이야기 — Next.js + Tailwind 모바일 인트로.

## 현재 범위

- 랜딩 화면 (시작하기 / 건너뛰기)
- 인트로 대화 장면 2개 (버튼·탭으로 장면 전환)
- 임시 CSS 배경 (아트 에셋 대체)

사주 계산, AI, DB, 결제, 복잡한 애니메이션은 포함하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인합니다.

## 빌드

```bash
npm run build
```
